# Barry 市场观察台

浏览器中的 A 股、国内商品期货和美股行情观察工具。买卖标记、搜索添加自选和 Wind 美股说明见 [买卖规则与自选](./买卖规则与自选.md)。新版本仍需在实际 Windows/Wind 客户端联调。

## Windows 本机 Wind 版

使用已验证能连接 WindPy 的同一个 Python，无需安装 Node.js。保持 Wind 登录，将整个项目解压后双击根目录的 `启动Wind看板.cmd`，浏览器会自动打开。也可在项目目录执行：

```bat
python tools\windows\wind_dashboard.py
```

WindPy 操作始终在主线程执行，HTTP 服务在后台线程提供页面。服务器只监听本机，且限制 Host。默认读取 `SH.510300`、`SH.600519`、`SHFE.rb`、`US.AAPL`、`US.SPY`，之后恢复本机保存的自选。页面搜索结果可直接添加新股票/基金，×可移除。`--symbols` 只用于首次默认列表，`--port` 选择端口，`--no-browser` 禁止自动打开浏览器。

每 5 秒轮询报价，分钟历史每 60 秒更新，不是逐笔推送。首次拉取最近三天 OHLCV，随后只重查最近一段时间以接收修正。所有 Wind 请求都为只读行情请求；首次及运行期间会使用账号的数据查询额度。请先验证默认品种，再增加订阅。

报价使用 `rt_last,rt_pre_close,rt_vol,rt_date,rt_time`，不使用 `result.Times` 查询时间替代源时间。美股报价与分钟时间的时区分别待核对，默认未确认时保留价格但停用买卖标记；可在说明与设置中分别指定。期货夜盘须核对自然日与交易日，程序不擅自修正。分钟数据从Wind分钟结束时间转换为共同结构的分钟开始时间，仅接受已收盘有效OHLCV。

图表在缺失分钟处断开，策略需重新积累 21 根连续有效数据。服务不会生成模拟价格作为 Wind 的后备值。关闭程序后数据清空，重新打开会再次补历史。详见根目录 `开始使用.txt`。

## 现在能做什么

- 观察 A 股股票、股票 ETF、国内商品期货主连、美股股票和 ETF，共 12 个预置示例。
- 按市场筛选自选；通过名称目录和代码校验搜索新增品种，保存到本机配置，可导入更多名称目录。
- 查看最近 60 根已收盘的 1 分钟收盘价走势、前收盘、累计成交量和源数据时间。
- 同时满足趋势、突破与放量条件时显示买入/卖出，其余留空；显示触发原因、历史B/S标记和ATR观察区间。
- 导出当前筛选结果为 CSV，文件保留模拟/外部行情标记和源时间。
- 数据过期、历史不足或连接中断时，暂停策略判断。

默认使用模拟价格，并在页面显著标注。模拟价格的初始数值不是任何日期的真实报价，不代表这些品种当前的走势、估值或交易机会。模拟模式不模拟交易所休市、涨跌停和连续合约换月。

真实行情模式不会生成价格。必须先通过行情服务适配器送入数据；切换到 live 本身不会接通供应商。接通后，实际延迟、可用市场及盘前盘后数据仍取决于订阅权限。

## Node.js 模拟开发模式

需要 Node.js 22 或更高版本，无第三方运行时依赖。

在仓库目录中执行：

```bash
cd /workspace/Barry
npm run check
npm start
```

默认监听本机 3000 端口。云端浏览器访问需要平台提供的访问入口；本项目尚未部署到公网。可以在自己的电脑安装 Node.js、下载此项目后运行。`npm run dev` 启用服务端文件变更自动重启。停止服务使用 Ctrl+C。

`HOST` 和 `PORT` 可覆盖监听地址和端口。需要通过平台代理访问时，由平台设置适当的监听地址；不要在未配置访问控制时将行情接口直接暴露到公网。

此文件与 `.env.example` 中的环境变量均为说明，程序不会自动读取 `.env`。

## 怎样看策略

策略只根据已收盘的 1 分钟 K 线计算，不把每次价格推送当成一根 K 线。至少需要 21 根连续且有效的分钟历史，计算最多使用最近 120 根。遇到缺失价格（例如 Wind 返回 NaN）或时间断档，就从断档后的有效数据重新累计；不会以零或上一价格填补。当前尚未接入交易所日历，休市间隔也会中断累计，因此开盘或午休恢复后的前 20 根分钟 K 线不产生策略。

- **趋势偏强**：EMA5 高于 EMA20，差值超过 `max(0.15 × ATR14, 最小报价单位)`。
- **趋势偏弱**：EMA5 低于 EMA20，差值超过上述阈值。
- **区间观察**：快慢均线差值未超过阈值。
- **突破观察**：最近收盘价是否高于/低于此前 20 根 K 线的最高价/最低价。
- **趋势失效观察**：参考收盘价逆趋势方向 `2 × ATR14`，最小距离为两个报价单位。
- **延伸观察位**：参考收盘价顺趋势方向两倍上述距离。

EMA 从最早一根输入收盘价初始化；ATR 是最近 14 根真实波幅的简单平均。它们是透明的观察规则，没有经过收益回测，也没有考虑手续费、滑点、涨跌停、资金规模或持仓。失效观察位不是保证成交的止损单。股票偏弱不表示账户可做空。

源报价超过 90 秒未更新，或最后已收盘 K 线超过 3 分钟未更新时，停用策略。正常休市也可能出现“过期”状态；当前尚无交易所节假日日历。界面显示上海时间，美股额外显示纽约行情时间。

人民币与美元分别显示，不合并成账户收益。期货主连不能直接下单；如需实盘参考，需选择具体合约并核对到期日、保证金和合约乘数。当前不连接交易账户、不提交订单。

## 接入真实数据

Wind、Capital IQ 和富途的接入安排见 [行情接入说明](./行情接入.md)。仍需确认接口授权、已购买的市场权限和允许的使用方式。不要将账号密码或密钥写入聊天、代码或 GitHub。

服务器使用 `MARKET_MODE=live`，并在安全环境中设置 `MARKET_INGEST_TOKEN`，然后重启。此凭据仅用于本工具接收适配器数据，与供应商登录凭据不同；浏览器无需也不应知道它。

以下是 Node.js 服务的通用接收接口。自定义适配器负责订阅行情、映射代码并补齐分钟 K 线，调用该接口；接口本身不是行情源。Windows 本机 Wind 模式直接由 Python 提供相同页面、快照和 SSE，浏览器复用同一份策略计算模块，不通过 Node.js 写入接口，也无需 `MARKET_INGEST_TOKEN`。

| 接口 | 用途 |
| --- | --- |
| `GET /api/health` | 检查进程、运行模式、写入认证是否已配置、新鲜报价数量 |
| `GET /api/snapshot` | 当前行情、历史 K 线及策略 JSON |
| `GET /api/events` | SSE 推送；每 3 秒刷新，接收新行情时立即刷新 |
| `POST /api/ingest` | 服务器间行情写入，仅 live 模式；需要 Bearer 认证 |

写入格式如下。数字仅用于说明结构，时间须替换为真实源时间：

```json
{
  "quotes": [
    {
      "id": "US.SPY",
      "timestamp": 1792728000000,
      "price": 600.12,
      "previousClose": 598.50,
      "volume": 120000,
      "bars": [
        {
          "time": 1792727940000,
          "open": 600.00,
          "high": 600.20,
          "low": 599.90,
          "close": 600.12,
          "volume": 1800
        }
      ]
    }
  ]
}
```

所有时间均为 UTC 毫秒时间戳。`timestamp` 是报价源时间，不得为虚构的新鲜时间。`bars[].time` 是分钟起始时间，须整分钟对齐，且已经收盘；不得补入虚构成交或用 tick 冒充 K 线。`previousClose` 需与当前交易日和复权口径匹配。`volume` 为源累计成交量，分钟成交量则放在 K 线内；适配器须明确股票的股/手、期货的单边/双边统计口径。期货夜盘的“交易日”不能简单按日历日计算。

每个请求接收 1–100 条报价，总大小最多 256 KB，每个品种一次最多提交 120 根历史 K 线。错误数据或乱序报价会使整个请求失败，不会部分写入；相同时间的 K 线按最新提交修正。报价和历史保存在内存中，重启后需适配器重新补充。

预置示例见 `src/instruments.json`。Wind本机版通过 `security_catalog.py` 和 `watchlist.py` 提供动态搜索、代码校验与订阅，不限于预置列表。名称目录的覆盖范围、ETF及美股名称导入方式见新增说明。特殊证券或新期货品种仍须核对报价单位、币种和合约信息。

## 验证范围与下一步

`npm run check` 覆盖上行/下行策略、未收盘 K 线排除、过期停用、缺失价格和分钟断档保护、数据恢复、数据校验、写入认证、批次原子性、模拟推送以及 live 空数据状态。

`python -m unittest discover -s test -p "*_test.py" -v` 验证 Wind 数据转换、本机服务、源时间与读取时间分离、无日期时停用以及 NaN 修正处理。Linux 环境使用 `python3`。

仍需本机验证动态名称目录与新增证券权限、Wind美股时区和分钟数据、期货夜盘口径，并完成历史回测、交易所日历等工作。当前统一采用Wind，无需为本版本安装富途OpenD。
