# Barry 市场观察台

短线、中线波段观察与主动提醒工具。完整规则和统计口径见[买卖规则与自选](买卖规则与自选.md)。

## Windows使用

1. 保持Wind登录；使用此前已验证WindPy可连接的Python。
2. 下载整个GitHub项目ZIP，全部解压到新文件夹。先在旧命令窗口按Ctrl+C关闭旧服务。
3. 双击根目录“启动Wind看板.cmd”，无需Node.js。
4. 搜索代码或名称，在结果中添加自选。切换短线/中线查看规则和历史评估。
5. 在“提醒设置”开启总开关，选择短线/中线、桌面和声音；允许浏览器通知，点击测试。网页保持打开即可监控全部自选；关闭网页后不提醒。
6. 如需判断自己的目标价/亏损，在详情“我的持仓参考”填写当前周期的买入价、日期和买入后最高价。

默认沪深300ETF、贵州茅台、螺纹钢主连、苹果和SPY；之后恢复保存的自选。首次加载日线和60分钟历史可能较慢并消耗Wind查询额度。所有供应商请求保持主线程、只读，不提交订单。

报价约5秒查询，历史约60秒更新。新入场判断等待完整60分钟收盘，不在每次报价跳动时产生新信号。目标/成本风险参考在实时报价更新时检查。不要把右上角时钟更新当成源行情已更新。

短线20交易日、目标5%，中线60交易日、目标20%；峰值回撤和成本亏损默认分别10%/20%，可调整。成功率是当前窗口的保守历史评估，不是独立验证的未来概率。手续费按要求忽略。

美股时区确认前只显示价格；期货的此版波段提醒/成功率暂未启用。真实Wind的WSD日线、WSI BarSize=60、交易日历与复权一致性仍需客户端联调。浏览器/系统禁止通知、休眠、冻结或勿扰会影响提醒，先使用测试按钮核对。

## 开发模式

Node.js 22+，无第三方运行时依赖。运行npm run check，然后npm start；默认本机3000端口，HOST/PORT可覆盖。模拟模式的行情和评估均为生成数据。Windows真实入口使用Python标准库和终端提供的WindPy；云端不能读取本机客户端。

运行Python检查：PYTHONDONTWRITEBYTECODE=1 python3 -m unittest discover -s test -p '*_test.py' -v。

Node通用live接收接口保留分钟级输入兼容性；它没有完整波段历史接入，不能仅切换MARKET_MODE=live就得到波段信号。真实使用请运行Wind本机入口。

自选目录保存于Windows用户LOCALAPPDATA/BarryMarketWatch/settings.json；持仓参考、风险设置、提醒开关和记录保存于当前浏览器同源localStorage。浏览器换端口或清除网站数据会清空后一类设置。勿在代码、聊天或浏览器输入账号密码。

Capital IQ与另一台电脑的Bloomberg资料可通过Excel导出CSV导入详情“补充资料”，参见[多来源资料](多来源资料.md)和[CSV表头模板](补充资料导入模板.csv)。这些是手动快照，不是API直连，也不改变已固定的交易规则。
