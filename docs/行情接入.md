# 行情服务接入

本项目提供 Windows 本机 Wind 适配器、Node.js 模拟模式及通用行情接收接口。供应商账户、WindPy、凭据和真实行情记录不随代码分发。

## 数据源安排

| 服务 | 用途 | 前提 |
| --- | --- | --- |
| Wind 本地终端 | A 股、ETF、国内商品期货、美股股票和 ETF | Windows 上已登录终端；Python 可导入 WindPy，具备 Client API 与相关市场权限；美股时间口径须另行确认 |
| 富途 OpenAPI | 可选的后续备用数据源 | 当前版本不要求安装 OpenD；适配器尚未实现 |
| Capital IQ | 后续公司财务和估值研究 | 需单独确认 API 授权；网页登录不等于接口授权 |

## 本机 Wind 运行

完整下载并解压项目，打开 Wind 并登录后，双击根目录的 `启动Wind看板.cmd`。使用的 Python 应与已验证 WindPy 成功连接的解释器相同。无需 Node.js、云端凭据或交易密码。

首次默认订阅沪深300 ETF、贵州茅台、螺纹钢主连、苹果和 SPY 五个示例，之后恢复已保存的自选。页面可按代码或已加载的名称搜索、添加和移除，详见[买卖规则与自选](买卖规则与自选.md)。首次读取约800自然日日线及180自然日60分钟OHLCV，之后增量刷新，新交易日重取全窗口统一前复权口径；查询消耗账号数据额度。主连仅用于观察，不是可直接交易的合约。

本机 HTTP 服务只监听本机地址，不开放订单接口。WindPy 调用在主线程，网页服务在后台线程。程序不安装或打包供应商 SDK，不索取账号密码，不解锁交易。更改端口或关闭浏览器自动启动，可使用 `--port` 或 `--no-browser`。

## 时间与缺失值

- `RT_TIME` 按 HHMMSS 解析，例如 `153011.0` 对应 15:30:11。
- `result.Times` 不用作源报价时间。页面另列“读取时间”，不把新一次查询当成源报价已更新。
- 程序另行请求 `RT_DATE`。其在特定账号、终端版本、市场下的可用性和含义需本机验证；不支持时保留价格展示，暂停策略。
- 期货夜盘必须核对自然日和交易日，程序不自行推算未知日期，也不接受超前时间。
- 波段数据通过 WSD 日线（PriceAdj=F）、WSI 60分钟线（BarSize=60;PriceAdj=F）、TDAYS 交易日历查询。波段60分钟时间是区间结束时间；只使用已经结束的区间，日线不含当日。遗留分钟接口仅为兼容保留。
- 美股报价和分钟数据的时区分别配置，默认均为待确认。确认前只展示报价和原始时间，暂停美股分钟图与买卖标记；不从时间数字猜测 UTC 或美东时间。
- NaN、负值和不可能的OHLC保留缺失占位，不补零或前值。交易日历中的缺失日线中断均线预热，持仓期间缺失数据使评估记为不确定。

## 首次联调需检查

1. 在本机确认行情价格、单位和时间与 Wind 终端一致。
2. 核对 `RT_DATE`、`RT_TIME` 的含义和延迟；休市时应显示过期行情，不产生策略。
3. 核对股票、ETF的日线/60分钟权限、TDAYS交易日历、区间结束时间及两个接口前复权的一致性。期货波段功能暂不启用。
4. 确认中断登录、数据缺失和权限错误时页面停用相应策略。

开发环境已用测试夹具验证数据转换、本机 HTTP/SSE、共享策略、搜索添加与浏览器流程。这不能替代真实 Windows/Wind 完整联调，也不证明策略收益。各市场均通过 Wind 查询，缺失行情不会用模拟价格替代；美股分钟权限、时间口径及新代码查询仍需在实际客户端核对。
