本轮新增A股研究规则与本地资料导入，尚无新增胜率结论。原价量、市场过滤和回调实验保留。20/60日、5%/20%目标、双重风险限制、T+1和忽略手续费的约定沿用。看板没有启用本轮新增过滤器。

更新：已增加[Wind宏观自动采集](Wind宏观自动接入.md)，预置用户提供的三项EDB编号，支持历史数值读取与看板定时更新。下述CSV仍用于有可靠首次公布版本的资料；自动EDB记录按本机实际观察时刻生效，两种版本分开研究。新闻流尚未接通。

## 怎样运行

Terea 空模板验证后的真实资料准备与固定来源执行命令见 [宏观事件最小核验方案](宏观事件最小核验方案.md)，三张可导入空模板位于 `docs/context-verification/`。该方案先核验字段、历史版本与覆盖证据，不改变本页规则。

1. 解压新版，双击 **完善模型并复用最近回测.cmd**。只需已安装的Python，不需要重新读取20只股票，也不连接Wind。
2. 程序寻找本机最近的原始“回测数据.json”，保留名单、价格和研究日期，另存新报告。还会打开 `%LOCALAPPDATA%\BarryMarketWatch\research_context` 资料目录。
3. 首次只有空模板，增强实验应显示“未评估”，表示待资料，不表示零胜率。
4. 导入经核验的历史资料后再次双击，检查校验问题、覆盖时段及增强/对照结果。

不需要自己补写过去的新闻利好利空判断。应先确认Wind或Bloomberg能否导出带首次公布时间和历史版本的资料。供应商字段映射需要核对，不能编造代码。今天的最新数值、修订后的历史序列、事后新闻分类不能当作当时已知的信息。未确认时间的资料继续标为待数据。

原始资料仅保存在本机，不自动上传。结果JSON包含来源文件指纹、校验问题、覆盖统计与派生逐笔记录，不包含完整宏观和新闻档案。不需要账号密码。覆盖声明仍需供应商核验，程序不能独立证明其完整性。

## 固定的待验证规则

新增三个实验以“价量＋市场趋势过滤”为起点，退出保持一致：宏观过滤、事件过滤、宏观＋事件过滤。暂不自动增加仓位，不把新闻情绪评分当作上涨概率。

**宏观模块同时要求资金面、PMI资料可用。**

- 资金面：DR007减同日适用的央行7天逆回购操作利率；两期观察都高于25bp时暂停新买入。利率输入百分数，1.8代表1.8%，不是0.018。最新观察日超过5个自然日、两期相隔超过7日视为未知；长假可能损失覆盖。
- PMI：国家统计局制造业PMI最新值低于50，且较上月下降至少0.5时暂停新买入。要求连续两个月首次公布值；最新统计期距决策超过45个自然日视为未知。不混用其他机构PMI，不提前使用尚未公布的月度数值。

25bp、0.5及有效期都是预先记录的研究假设，没有盈利优化，也未证明最优。本轮未实现汇率、财政冲击、海外利率、盈利改善和行业供需的联合模型。

**事件模块区分资料展示与暂停新买入。** 政策支持不直接触发买入；支持政策、地缘政治、已知宏观/财报日程、公司/市场风险。作用窗口最长30天。缺少历史行业映射，本轮只支持全A股或明确证券代码。

消息首次可获得、影响分类实际完成、作用窗口开始，三个条件都达到后才生效。今天才作出的历史影响判断，不能回头改变过去的交易。历史供应商标签也须有当时分类的证据。

信号出现时检查一次，下一小时开盘准备买入时再检查。隔夜重大消息可以取消待买入；已有持仓的目标、风险、趋势和到期退出持续计算，不因资料缺失隐藏风险。

## CSV字段

使用UTF-8并保留模板表头顺序。时间必须含时区，例如 `2026-10-28T09:30:00+08:00` 或明确UTC时间。只有日期时不猜测发布时刻。source填写来源，reference填写可核验的记录编号或链接。

`macro.csv`：

| 字段 | 含义 |
| --- | --- |
| indicator | `cn_funding`或`cn_pmi` |
| observation_date | 资金实际观察日；PMI统计月份最后一天 |
| available_at | 实际首次可获得时间 |
| value | DR007百分数或制造业PMI指数 |
| reference_value | 同日适用的7天逆回购利率百分数；PMI留空 |
| unit | 资金为`percent`，PMI为`index` |
| vintage | 只接受`first_release`，仍需原来源证实 |
| source / reference | 来源和依据 |

同指标同观察期重复记录会报错，不平均多个来源，不用修订值冒充首发值。

`events.csv`：

| 字段 | 含义 |
| --- | --- |
| id / scope | 唯一编号；`CN`或完整沪深代码如`002466.SZ` |
| event_type | `scheduled_macro`、`scheduled_earnings`、`company_risk`、`market_risk`、`policy`、`geopolitics`之一 |
| action | `information`或`pause_new_entries` |
| available_at | 消息首次可获得时间 |
| assessed_at | 影响分类实际作出时间，不得早于消息时间 |
| start_at / end_at | 作用窗口，含起点、不含终点，最长30天 |
| source / reference / note | 来源、依据、简短说明 |

`coverage.csv`：`scope,start_at,end_at,source,reference`。分别声明市场和每只股票的档案覆盖范围。仅有CN不能证明公司消息齐全；空事件表不能替代覆盖声明。不能只挑有利日期声明覆盖。

一条异常记录就会暂停对应模块：宏观错误影响宏观和组合；事件/覆盖错误影响事件和组合。错误不会被静默丢弃后继续报告盈利。

## 怎样比较

每个增强实验另设市场过滤对照。两组只在同样具备资料的决策时段允许新开仓，开盘再次检查覆盖。未知资料、已知不利条件分别统计；未知时段不计失败交易，也不算条件通过。

报告列出全期、前段、后段和跨界交易。增强逐笔在`trades`，共同覆盖对照逐笔在`comparisonTrades`，对照统计在`contextComparisons`。组间有重复交易，不能合并灌大样本。

这些单笔统计不能替代账户回测。后续仍需同时持仓、资金占用、空仓时间、行业集中、实际成交能力与组合回撤，再与相同期间和资金约束的基准比较。不能用平均单笔收益减去大盘全年收益作为超额收益。

目前20只股票和三年资料已经看过，新增规则属于探索。先验证数据和共同覆盖，再固定规则扩大随机样本，在不同阶段、新的独立资料与前向模拟中检验。没有宏观/事件历史时不给新增规则胜率。
