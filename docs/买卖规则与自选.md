# 买卖标记与搜索自选

## 买卖规则

初始版本以已收盘的 1 分钟 OHLCV 计算，不将价格每次更新都视为一根 K 线。参数是待回测的基线，尚未验证收益，不是对个人账户或成本的判断。

| 标记 | 同时满足的条件 |
| --- | --- |
| 买入 | EMA5 高于 EMA20，差值超过 `max(0.15×ATR14, 最小报价单位)`；最新收盘价高于此前20根最高价；成交量≥此前20根平均成交量的1.2倍 |
| 卖出 | EMA5 低于 EMA20，差值超过同一阈值；最新收盘价低于此前20根最低价；成交量≥此前20根平均成交量的1.2倍 |
| 留空 | 上述条件未全部满足，或数据过期、断线、缺失、未收盘、时间口径尚未确认 |

表格和选中品种只显示实际触发的“买入”“卖出”，不会将“趋势偏强”直接转换成买入。当前报价还必须保持在对应突破位之外；价格退回突破区间时撤掉当前标记。图上的 B/S 是当时已收盘数据触发的历史标记，不代表当前建议。当前报价过期时，不再显示当前买卖标记；历史触发记录仍可用于查看。

触发时提供以2×ATR为距离的趋势失效观察位和延伸观察位，它们不是保证成交的止损或止盈订单。股票、ETF的卖出标记供已有持仓参考，不代表可做空，也不知道个人买入成本。A股和普通股票ETF须考虑T+1，分钟信号不能直接变成当日买卖闭环。期货主连不能直接下单。

目前持有周期参数仍待产品联调确认；正式采用其他周期时，应先调整数据粒度与历史长度并回测，不用短短120分钟数据冒充日线或波段策略。尚未实现持仓止损、手续费/滑点回测、节假日日历和自动交易。

## 搜索与添加

1. 在页面上方输入证券代码或名称。搜索与自选列表筛选分开，不会只搜索原来的12个示例。
2. 在搜索结果中核对名称、代码、品种类型，点击“添加”。
3. 看板会将该品种加入实际 Wind 查询，并补充历史数据。最多50个自选，以控制数据查询额度。
4. × 可移除品种。关闭并重启程序后，自选会恢复。

支持 `600036`、`600036.SH`、`SH.600036` 等代码形式。美股可用 `AAPL.O`、`SPY.P`、`MSFT.O` 等完整 Wind 代码；输入普通美股 ticker 时，依次通过 Wind 的证券名称接口校验候选交易所后缀，不将未校验的代码冒充可用证券。

Wind 本机版使用 `WSS sec_name` 校验新代码。启动时尝试加载 Wind 沪深 A 股名称目录，目录或基础资料也受账号权限限制。名称搜索覆盖当前已加载的目录，不宣称默认拥有全市场ETF和美股中文名称。ETF、美股可按完整代码查询；如需更多名称，可从Wind导出目录后点击“导入名称目录”。

CSV 接受 UTF-8（含BOM）和常见 GBK/GB18030 编码。列名可为 `wind_code,sec_name` 或 `证券代码,证券简称`。这只导入证券元数据，不导入凭据或伪造行情。示例：

```csv
wind_code,sec_name
513500.SH,标普500ETF
MSFT.O,微软
```

本机配置保存在 Windows 当前用户的 `LOCALAPPDATA/BarryMarketWatch/settings.json`，只保存自选元数据、导入的名称目录和美股时区选项，不保存账号、密码、报价或持仓。更新程序时不需要覆盖该文件。损坏配置会报错，不会被盲目覆盖。`--state-file` 可指定其他本机路径。

## Wind 美股

美股同样通过 Wind 查询，与国内市场分组请求。美股查询失败或没有权限不会阻断国内报价。默认新增苹果和SPY两个示例，可在搜索中添加其他品种。

Wind 美股 `RT_DATE/RT_TIME` 与 WSI 时间口径分别待确认，不根据“20:01”等数字猜测UTC或美东时间。确认前显示原始报价和时间，暂停美股买卖标记与分钟图。拿到 Wind 的口径后，在“使用与规则设置”中分别设置报价、分钟数据时区。选择美东时间使用系统时区数据库；Windows若缺少数据库，会明确提示安装 `tzdata`，不使用固定时差替代夏令时。

## 开发验证

Node.js模拟模式只提供有限的演示名称目录，支持真实的添加/移除交互，但价格是生成数据。Wind名称目录、WSS新增品种权限和美股分钟数据仍需在实际Windows客户端验证。

自动测试验证条件触发与留空、未收盘数据不触发、历史标记无前视、名称查询、代码校验、实际订阅更新、重启恢复、目录导入、时区未知停用以及跨来源请求拒绝。测试夹具不是实际行情回测。
