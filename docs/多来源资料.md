# Wind、Capital IQ 与 Bloomberg

当前安排：Wind提供行情、日线和60分钟数据；Capital IQ用Excel导出资料；Bloomberg在另一台电脑，用该电脑的Excel导出后转移CSV至看板电脑导入。网页账户或终端登录不自动表示具有API权限。程序不索取账户密码、不爬取登录页面，也未配置跨机Bloomberg连接。

## Excel资料导入

1. 在Capital IQ或Bloomberg Excel中按自己的权限获取资料。
2. 复制本仓库 docs/补充资料导入模板.csv 的表头到Excel；每行对应一只证券。
3. wind_code填与看板相同的完整Wind代码，例如600519.SH、AAPL.O、SPY.P；as_of填写资料实际数据日期YYYY-MM-DD。不要把导出当天当成财务报告期。日期未知可留空，页面会显示“未提供”。
4. 支持列：PE_RATIO（市盈率，倍）、PX_TO_BOOK_RATIO（市净率，倍）、EQY_DVD_YLD_IND（预期股息率，百分数）、CRNCY（币种）。也支持列名“证券代码、数据日期、市盈率、市净率、股息率、币种”。百分数应填百分数值，不是Excel底层小数。
5. 另存UTF-8 CSV（常见GB18030编码也支持）。在证券详情“补充资料”选择来源，再点击“导入资料CSV”。
6. 切换证券查看各自资料。两家同名字段并列展示，不混成一个数值；注意口径、币种和数据日期的差异。导入是手动快照，不自动刷新，不影响既定买卖规则。

模板只有表头，不包含虚构估值。其他资料可用长表格式：wind_code,source,field,value,unit,as_of。source取Bloomberg或Capital IQ。可用自定义field保存财务/研究指标或文字。需自行明确单位和实际数据时点；不宣称已接通新闻流、研报全文或CIQ API。

资料存于Wind看板电脑的 LOCALAPPDATA/BarryMarketWatch/research.json，不上传到云端、不进入Git仓库。配置保存失败不覆盖原数据。导入同一证券、来源、字段会更新该项；本版保留最新值，不是完整财务历史库。最多5000项。

## 可选的Bloomberg Desktop API适配器

代码保留同机本地只读适配器。只有将来在同一电脑运行Bloomberg和看板，且对应Python已正确安装Bloomberg官方blpapi、终端登录、Desktop API授权可用，才使用帮助中的可选接口。跨机连接本版未配置，默认不查询，不开放远程端口。

按需查询参考资料服务 //blp/refdata 的 PE_RATIO、PX_TO_BOOK_RATIO、EQY_DVD_YLD_IND、CRNCY。缺失字段不造值，证券代码映射及字段适用性需核对。该接口未请求各字段的数据实际时点，页面显示时点未提供，并另列读取时间。它不是实时新闻或交易接口。

适配器在独立后台线程中运行，不阻塞Wind主线程报价；接口失败不会替换Wind行情或改变买卖信号。不要求为了看板的行情和提醒功能安装此SDK。实际Bloomberg终端连接尚未验证。
