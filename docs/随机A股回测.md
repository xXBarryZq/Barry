# 随机A股回测：先检查是否值得继续研究

理论目前是可以检验的假设，还不是已经证明有效的策略。本工具让已有Wind连接的Windows电脑直接读取历史资料，不需要再提供账号密码，不下单，不改变市场观察台的买卖逻辑。

已有原始回测数据时，可双击 **完善模型并复用最近回测.cmd**，在相同股票历史上增加宏观与事件过滤研究。规则、数据字段及缺失处理见[宏观与事件模型](宏观与事件模型.md)。首次空模板显示“未评估”，不代表已接通新闻或得到新增胜率。

下载并完整解压项目后，保持Wind登录，双击根目录的 **启动随机A股回测.cmd**。默认按研究开始日期申请当时的沪深A股目录，固定随机种子20261028抽取20只，读取近3年日线和60分钟资料。报告自动在浏览器打开。历史请求可能较慢并占用Wind数据额度，黑色窗口显示当前进度；不要重复启动多份研究任务。

程序先保存固定抽样计划，再用沪深300ETF和贵州茅台检查近期数据链路；两者都失败则停止批量查询，自动打开“接口诊断.html”。这时还没有策略盈亏结果，不要把“数据读取失败”当成“交易亏损”。也可单独双击“启动Wind回测诊断.cmd”，只检查近期数据，无需重跑20只。

研究目录申请日期是否由接口返回，会在报告注明；没有返回日期时，不能独立确认历史目录，存在幸存者偏差风险。不含北交所和ETF，不包括研究开始后上市的股票。抽样名单在查询价格前保存，某只股票读取失败不换另一只。不会从最终涨幅最好的一组里挑“随机”样本。

报告比较：现有价量规则、增加市场趋势过滤、短线回调入场的价量实验。三种版本共享现有JavaScript交易评估器，退出规则保持一致。市场参考优先使用中证全指；该接口不可用时，明确尝试沪深300ETF作为大盘代理。代理属于大盘股ETF，与全市场指数不同，报告与结果JSON都标注实际来源。选择依据是接口可用性，不按历史收益挑选代理；此分支是新增的探索性对照，不能称为原中证全指模型的独立验证。两者均失败时，相关方案显示“未评估”，不将其零交易当作策略结果。

回调实验只替换短线入场：此前日线价格高于EMA20且EMA20高于EMA60，近5日触及EMA20附近且日线收盘未跌破EMA60，完整60分钟收盘突破此前3根高点、量达到此前20个有效同一时段中位数的1.2倍，市场过滤通过。波动距离采用过去14日真实波幅的简单平均，不是Wilder平滑ATR。它没有实现完整研究方案的估值、行业和盈利筛选，也没有加入结构止损、最低盈亏比或日线EMA退出，报告不能称为完整增强理论的胜率。

短线仍是20个交易日目标5%、峰值回撤与成本亏损默认各10%；中线60个交易日目标20%、两项风险默认各20%。信号后下一根小时线开盘尝试入场，保留T+1、跳空和小时高低点顺序不确定的处理。达到目标后不继续计算退出后的回撤。手续费按用户要求忽略。

WSD日线正常时，以日线前复权与原始日线收盘之比作为统一复权因子，原始小时数据分段读取后按每日因子转换，避免不同请求窗口使用不同价格基准。15:00小时末价与同日日线收盘还会交叉检查，超过0.3%或复权后的两分钱容差即停止该样本，提示核对时间和复权口径。缺失小时保留空值，不补成价格；全小时最高等于最低或没有成交量时，不假定可以成交。未读取逐笔订单、完整历史涨跌停/停牌状态，其他成交限制和实际滑点仍没有完整重建；这只是明确假设下的价格收益近似，不是券商账户收益证明。

若WSD错误码为0却日线OHLCV全部为空，或原始收盘价无法生成复权因子，默认改用一次覆盖全部研究期及日线预热期的WSI请求，明确传入`BarSize=60;PriceAdj=B`。以同次请求的后复权小时线合成日线，避免依赖空的WSD数据，也避免混合多个查询窗口的复权基准。每个交易日必须有10:30、11:30、14:00、15:00四根完整有效的小时线；缺一根就保留缺失日线，不补价格。合成日线用于离线初步研究，尚不能与缺失的官方日线交叉核对。报告逐股标明日线来源和价格口径，网页策略不改变。

后复权价格可能明显高于屏幕上的实际报价；交易明细的entry/exitPrice是复权参考价格，不能当作历史实际成交报价。结果JSON和逐笔CSV的priceAdjustment字段，B表示后复权，F表示前复权。收益使用同一股票、同一口径的价格比例；统一比例缩放不会改变本工具的趋势/突破及百分比目标，但不能因此假定任何两家供应商或两种复权方法总是完全一致。分红现金流仍按前述价格收益近似处理。

如果复权小时请求也为空、时间口径不符或没有覆盖研究起点附近，则仍停止该样本，不自动改用未复权价格或缩短研究期。近期预检通过只能证明近期可读取，不能证明三年历史全部可用。`--daily-source wsd`只接受WSD日线；`--daily-source hourly`直接使用同次复权小时合成，默认`auto`按上述条件选择。

报告把严格达标率、一般赚钱比例、平均单笔收益、最差单笔、不确定交易、读取失败以及未结束持仓分别列出。平均收益只用无歧义的已完成样本，可能受缺失数据的选择偏差影响，不能代表全部样本，更不能当整个账户收益率。没有信号不算成功。报告展示逐股结果，支持保存结果JSON与逐笔CSV，便于复核是否真有盈利、利润是否只集中于少数标的。

前约三分之二和后约三分之一分别展示；跨分段持仓单列，不能冒充独立后段交易。这是固定规则的初步分段观察，不是已经完成隔离边界、封存数据和统计显著性检验的正式验证。样本太少时不估计未来胜率。初步表现差就应重新审视；初步表现好也仍需扩大样本、覆盖更多行情并做独立与前向检验。

历史原始资料和报告默认保存在 `%LOCALAPPDATA%\BarryMarketWatch\backtests\run-日期时间`，不上传GitHub。浏览器报告里的“保存结果JSON”包含派生结果和逐笔记录，不含账号、密码或整段行情；可以用它继续讨论结果，无需发送完整Wind原始数据。若报告未自动打开，可从黑色窗口显示的路径打开“报告.html”。

“保存接口诊断”可导出每阶段的错误码、字段有效数量和原始时间示例，不含整段历史价格、账号或密钥。诊断会区分WSD全空、复权日期不匹配、WSI返回0行、时间过滤、OHLCV缺失或成交量为0，不再笼统归因于权限或停牌。

已有报告提示市场指数失败时，保持Wind登录，双击“修复最近回测的市场参考.cmd”。它寻找本机最近一次成功保存了个股历史的“回测数据.json”，保留原来的样本、起止日期、个股日线和小时线，只补市场参考。新报告和新数据保存到新文件夹，原报告不覆盖，不需要重新读取20只股票。也可用`--repair-data "原回测数据.json完整路径"`指定来源。请保留原文件夹；从浏览器导出的“回测结果.json”不含完整历史，不能代替原数据文件补跑。

报告将“预热日线有效／应有”与研究期内缺失分开显示。缺少研究开始前的历史时，初期不能产生具备足够背景的信号；两个方案若有效数据覆盖不同，需要在共同覆盖区间再比较，不能把覆盖差异归功于市场过滤。补跑同一数据没有增加独立样本，仍需后续封存与前向检验。

需要扩大研究时，可在项目文件夹命令窗口运行 `python tools\windows\random_backtest.py --count 50 --years 5`。这会增加查询量，数据可用范围仍取决于Wind权限。`--seed`可更换种子，但看到结果后不断换种子再只报告最好一组，会产生选择偏差。应保留并报告所有试过的样本。

已保存的“回测数据.json”可用 `python tools\windows\random_backtest.py --from-json "完整文件路径"` 在本机重新生成报告，不再连接Wind。此工具在云端只用人工构造资料验证程序行为，没有读取用户Wind真实历史，也没有得到可宣称的真实盈利或胜率结论。
