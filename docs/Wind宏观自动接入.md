# Wind宏观自动采集

在已安装WindPy、Wind保持登录的同一台Windows电脑运行，不需要分享账号密码，也不需要开放电脑端口。云端不能直接访问本机Wind。本轮先接A股宏观数据，新闻流和海外宏观不包含在本次采集中。

## 本次历史回测

完整解压新版后双击 **自动拉取Wind宏观并回测.cmd**。程序找到最近一次保存的原始“回测数据.json”，保留20只股票、价格和日期，只新查询宏观，另存新报告。股票数据不重新读取，原报告保留。查询在独立子进程执行，最长90秒后可报告超时，不终止Wind客户端或其他Python进程。

同文件夹保存：`Wind宏观历史.json`（原始数值，仅保存在本机）、`宏观接口检查.json`（指标编号、数量、末期数值和错误码）、新报告与新的原始研究数据。需要检查接入时，提供较小的“宏观接口检查.json”即可，不必发送整段历史。

若显示三项均没有有效数值，先确认是否因 **API 流量配额超限**（Wind客服2026-10-28：Python EDB 空值/`-40522015` 无权限常因配额；按 **168小时** 滚动恢复）。配额不足时请勿反复诊断或长区间拉取。配额恢复后，优先用看板“立即读取”（默认约35天短区间），确认有有效 CLOSE 后再考虑历史回填。

需要对照诊断时，保持Wind登录，双击 **检查Wind宏观接口.cmd**（显式选择，会消耗配额）。它对每个编号比较近期约120天原始查询、近期`Fill=Previous`查询、原研究长区间查询，共最多9次EDB请求，不重新读取股票，也不写入宏观留档。结束后自动打开报告和目录，请提供“宏观接口诊断.json”。诊断记录原始字段、返回行数、空值/非数类型及最多3个末期样例；不会记录完整历史。填充选项仅用于检查，不会自动采用。已知配额症状会在报告中提示168小时恢复；其他错误码含义仍不自行猜测。

**自动读取历史数值不等于取得历史首次公布版本。** 官方WindPy EDB封装使用`Times`作为观察期日期；当前接口未验证历史首发时间与修订档案。程序不会把统计月份、读取时间或填充值冒充历史发布时间。新报告明确列出已读取数值及仍待核验的历史条件；普通EDB数值不能使采集前的严格宏观回测自动变为可评估。

## 今后的自动更新

双击 **启动Wind看板.cmd**，打开新增加的 **宏观数据** 页。默认已启用三项编号，每15分钟自动查询一次；可关闭或改为1、5、60分钟，也可点“立即读取”。只要Wind登录、本机程序运行，就会继续查询。电脑休眠、退出程序或Wind断开时不能保证更新；没有安装后台开机任务。

PMI通常每月变化，DR007通常按日变化，政策利率按调整变化。这里的自动更新是定时查询，不是新闻推送，也不承诺在官方发布瞬间到达。页面分别显示读取时刻与统计观察期。

每次实际首次读到的数值及后续修订，保存在 `%LOCALAPPDATA%\BarryMarketWatch\wind-macro.sqlite3`。旧值不覆盖；重复查询相同值不重复增加记录。配置在同目录`wind-macro.json`。编号改变后，新旧数据隔离，防止混用不同指标。电脑时钟倒退时拒绝新增倒置时间记录。不要删除本机留档，否则后续无法恢复从前采集到的版本。

前向背景版本使用“当时本机已经看到的最新版本”，策略编号`cn-macro-events-observed-v1`。它与要求历史首次公布值的原版分开研究。修订值仅从实际观察时刻起生效；不能拿今天取得的旧月份数值回测昨天的交易。

宏观查询使用独立进程，失败或超时不会阻塞价格轮询。部分指标失败会显示具体原因，保留已有本机记录；资料过期时背景判断转为待数据。**本轮宏观仅展示背景，尚未用于正式买卖标签或桌面交易提醒。** 是否启用仍取决于后续验证。

## 指标编号与口径

编号来自用户2026年10月28日提供的Wind代码生成器语句，程序已预置；实际接口权限和指标身份还需要本机返回/终端说明核对。数值范围检查不能独立证明名称和单位正确。

| 指标 | EDB编号 | 单位 |
| --- | --- | --- |
| 国家统计局制造业PMI | M0017126 | 指数 |
| DR007 | M0041502 | % |
| 央行7天逆回购操作利率，按当日适用状态 | M0325686 | % |

采集使用官方调用形式`w.edb(编号,开始日期,结束日期,"")`，不执行粘贴的Python代码，不擅自添加未知的首发版本参数。未使用`Fill=Previous`填补PMI或DR007；缺失值保留缺失。按用户指定的“政策利率状态”口径，计算某日利差时可以采用该日之前已知且尚未被后续政策观察替代的利率状态，记录其原观察日期；不会使用未来的政策利率或向前填补DR007。月度观察期不是月末时不自行改写日期，相关PMI背景保持待核验。

如编号需要调整，可在页面输入单个EDB编号或对应单指标的`w.edb(...)`语句。只提取编号，不执行其余代码；三个指标不能误填成同一编号。不要把逆回购操作金额、财新PMI或其他利率当作这三项。

已核对的Wind官方封装：[WindPy.py固定版本](https://github.com/WindQuant/Official/blob/0a0d6ca5d1501443a17b0e7c2caf5cf9e1e61936/WAPIWrapper/WAPIWrapperPython/WindPy.py)。此证据仅确认EDB调用形式和日期返回方式，不证明特定账号权限或宏观策略收益。
